# blmodkit - ملخص بالعربي

أداة للمودرز تخليهم يضيفون شخصيات إضافية للعبة Burst Limit على الكمبيوتر. الشخصيات تظهر في صفحة
**R2** بشاشة اختيار الشخصيات في Versus وTraining.

**الأداة ما فيها أي ملفات من اللعبة.** كل أمر يقرأ اللي يحتاجه من نسختك (`LONG2DATA_US.CPK`
و`default.xex`) وقت التشغيل.

**المتطلبات:** Python 3.9 أو أحدث، و`pip install -r requirements.txt` (يثبّت numpy وPillow).

## الخطوات

1. **حدد مكان اللعبة (مرة وحدة):**
   `python -m blmodkit config --game "<مجلد game_data_root>"`
2. **سوِّ شخصية جديدة من شخصية موجودة:**
   `python -m blmodkit new-slot --base VGT --code TST --name "Test Vegeta" --out "<مجلد اللعبة>\mods\Test_Vegeta" --enable`
   - ينسخ ملفات الشخصية الأساسية بأسماء الكود الجديد.
   - يعطي كل texture رقم (handle) خاص فيها، ويغيّر اسم مجموعة الـtextures داخل ملفات NUX، عشان
     ما تتداخل مع الشخصية الأساسية.
   - يكتب `slot.toml` (فيه شرح لكل سطر) و`mod.toml`، وصور مؤقتة.
3. **الصور:**
   `python -m blmodkit art --src صورة.png --mod <مجلد المود>`
   - من صورة وحدة يسوي الكرت (512x120) والصورة الكبيرة (368x720) ووجه الـHUD (236x268) بستايل اللعبة.
   - افتح `art\<CODE>_art_preview.png` وشيّك عليها. لو مكان الوجه غلط، استخدم `--face X,Y`
     و`--face-size`.
4. **موديل جديد:** `python -m blmodkit import-model --help`. الشرح الكامل في README.md (قسم 3).
5. **لون المؤثرات (اختياري):**
   `python -m blmodkit recolor-fx --mod <مجلد المود> --hue 120` (120 = أخضر)
6. **الفحص:**
   - `python -m blmodkit check <مجلد المود>`: يفحص المسارات والأحجام وتعارض الـtextures والأسماء
     والصور والصوت.
   - `python -m blmodkit hits --mod <مجلد المود>`: محاكاة الضربات ضد Goku وKrillin.
7. **داخل اللعبة:** أعد تشغيل اللعبة. في شاشة اختيار الشخصيات اضغط **R2**، وY لتغيير اللون.
   أوفلاين فقط.

## المشاركة

لا ترفع مجلد المود زي ما هو، لأن فيه نسخ من ملفات اللعبة.

- شارك بس الأشياء اللي سويتها بنفسك: الموديل، الصور، الحركات، الصوت، و`slot.toml`.
- اكتب للاعبين أمر `new-slot` نفسه عشان كل واحد يبني الباقي من نسخته.

التفاصيل كاملة في README.md.
